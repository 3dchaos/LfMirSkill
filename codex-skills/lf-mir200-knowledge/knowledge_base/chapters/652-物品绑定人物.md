# 物品绑定人物

**功能：**
    物品绑定人物

绑定类型:
    帐号，角色名，IP

命令格式:
    @BindUseItem 人物名称 物品类型
绑定类型
例：@BindUseItem 人物名称 武器 帐号
此时将指定的人物及其身上的武器绑定在该人的帐号上
========================================================

物品类型:
衣服，武器，照明物，项链，头盔，左手镯，右手镯，左戒指，右戒指，物品
腰带，鞋子，宝石

BindUseItem
    显示绑定物品到人物信息

ShowUseItemInfo

显示人物身上带装备信息
