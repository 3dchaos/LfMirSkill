# 排序在线人物自定义变量[!]

功能: 排序在线人物自定义变量.
格式: SortHumVarToList 变量类型(HUMAN,GUILD,GLOBAL) 变量名 保存路径 排序模式(0,1)
名字路径
说明: 排序模式 0=升序,1=降序

名字路径在排序后只保存人物名字不保存人物变量.
注意: 此脚本命令只排序在线人物的变量


升序排序人物变量QQQQ:
[@main]
#IF
#ACT
SortHumVarToList
HUMAN QQQQ ..\QuestDiary\测试.txt
0


升序排序人物变量QQQQ,单独保存人物名字:
[@main]
#IF
#ACT
SortHumVarToList
HUMAN QQQQ ..\QuestDiary\测试.txt 0
..\QuestDiary\测试1.txt
