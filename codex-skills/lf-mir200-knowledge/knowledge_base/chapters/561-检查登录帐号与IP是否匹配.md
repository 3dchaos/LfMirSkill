# 检查登录帐号与IP是否匹配

**功能：**

可以检查登录帐号与IP是否匹配。

**格式：**CHECKACCOUNTIPLIST
AccountIPList.txt

;==========================================
;检查人物的等级是否等于指定级别
[@checklevel0]
#IF

CHECKACCOUNTIPLIST
AccountIPList.txt
#SAY
您的登录帐号与指定IP匹配。
#ELSESAY
您的登录帐号与指定IP不匹配。
;==========================================

**列表文件格式:**此文件们于目录：Mir200\Envir\

AccountIPList.txt

;==========================================
;登录帐号 IP
lintest
192.168.1.123
lintest1
192.168.1.124
;==========================================
