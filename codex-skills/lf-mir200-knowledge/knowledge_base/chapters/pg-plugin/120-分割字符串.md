# 分割字符串

分割字符串
PGExtractString

参数1：分隔符
参数2：待分割的内容
参数3：变量名，用于保存分割后的内容，内容保存在变量名\_1、变量名\_2、依次类推
，注意此变量只能使用扩展变量
参数4：变量名，用于保存分割得到的数量

实例

[@main]
#if
#act
PGExtractString | 测试文本1|测试文本2
S$测试变量
N0
SENDMSG 6 你将文本分割了，并将分割后的内容保存在变量【S$测试变量\_1】和【S$测试变量\_2】中，他们的值分别是<$STR(S$测试变量\_1)>和<$STR(S$测试变量\_2)>，分割后共获得了【<$STR(N0)>】个内容
