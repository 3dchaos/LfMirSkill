# 修改物品来源

PG3.43新增修改物品来源

PGCHANGEMAKEITEMINFO

//参数1: 装备位置 （0-31）
//参数2: 类型(0没有物品来源 1GM 2NPC 3商铺 4怪物 5系统 6挖矿)
//参数3: 地图名称（不能为空）
//参数4 人物名称(如果没有用\*代替,不能为空)
//参数5: 怪物名称(如果没有用\*代替，不能为空)
//参数6: 是否修改物品来源时间（1为修改当前时间，0为不修改)

实例：

[@main]
#act
PGCHANGEMAKEITEMINFO 0 1 3 \* \* 1
;代表 衣服 修改成GM制造,并且修改为当前系统时间

可用常量：

<$MapTitle> 取地图名称

<$USERNAME> 人物名称
