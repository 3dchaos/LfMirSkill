# 宝宝范围百分比切割

PG3.3.9新增宝宝专用范围百分比切割(加强)

PGBDelMonHpEx

请在宝宝物理攻击触发[@PGSLAVEATTACK]和宝宝魔法攻击触发[@PGSLAVEMAGICATTACK]字段下使用,其他地方使用有可能会导致引擎出错

参数1：百分比或切割值

参数2：0:以当前HP的百分比 1:以参数1的值切割 2:以最大HP的百分比

参数3：0不判断嘲讽 1判断嘲讽过的怪才切割

参数4：0以自身范围 1以攻击目标范围

参数5：X坐标

参数6：Y坐标

参数7：范围

参数8：0都切割 1:本次切割只切割角色，2:本体切割只切割英雄，3:本次切割只切割怪物。

参数9：分母基数(<=100等于100)

例子1：
#ACT

;切割自身5格坐标范围的怪物 10%最大生命值的伤害
PGBDELMONHPEX 10 2 0 0 <$X> <$Y>
 5 3
