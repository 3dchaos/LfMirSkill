# 玩家提示插件加载失败

玩家提示插件加载失败
这个问题分2类情况：
一.全体玩家或者大部分玩家加载失败，可能性有

1.G盾控制台没有打开，或者到期了，或者机器码变动（比如加IP，多IP机器也可能自动变），或者卡号被人解绑换到别的机器上了。
2.G盾插件安装顺序出错，在mir200/pluglist.txt这个文本里面，G盾的插件一定要在最后位置，如果不在，则必出问题，这情况只有A版会出现。
3.用了不正确的游戏网关，比如把其他的反挂网关拿来用了，比如一万网关，都是不支持的。

G盾A版只能使用GOM原版网关，G盾B版只能使用G盾版本压缩包里自带的网关。
4.使用PJ和XF登陆器的用户，在配置登陆器的时候选择了有签名。 如果选了有签名任何插件都无法加载，所以一定要选无签名。

二。个别玩家G盾加载失败，可能性有

1.玩家网络太差：使用wifi玩的，4G流量玩的，还有偏远地区的，奇奇怪怪小电信公司的宽带，路由器重启下看看。
2.玩家电脑垃圾太多，使用360清理下电脑垃圾就好了
3.开挂玩家，故意让G盾加载失败，据我们所知，是有外挂专门这么做的，阻止G盾加载，然后在G盾1分钟超时掉线之前小退，再上的，

这种玩家就是为了躲避G盾检测为了使用外挂的。如果在G盾的在线列表上总是看到同一个人一直是插件未加载的话，可以考虑封号处理。
