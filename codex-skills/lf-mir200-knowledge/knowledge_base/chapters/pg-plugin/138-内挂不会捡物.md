# 内挂不会捡物

### **内挂不会捡物**

部分人有特殊的需求，他要求内挂可以自动挂机，或者可以自动捡物。

**这和****G****盾上的隐藏地面物品功能冲突了，如果一定需要内挂会捡物，那么，请关闭****G****盾上的隐藏地面物品。**

![https://img.kancloud.cn/2a/89/2a89f4262380050538ccee9d426426db_651x624.png](../../assets/pg-plugin/PG插件3.48使用说明书/G盾游戏安全防护使用说明书/内挂不会捡物.files/image002.gif)

关闭之后，反挂机功能会损失一部分。
