# 关于漏洞被刷

### **我所知道的漏洞如下：**

目前引擎漏洞有2大类：第一类是GOM作者故意遗留的，防止破解引擎留下的暗桩。如果不处理，则可能会M2无限重启卡死,无限元宝，NPC无效,装备丢失等。
这种的，如果没有用去后门插件，则会不定时的自动爆发。

第二类是在长达几年的使用过程中，被发现的当初作者没考虑周全的地方。有刷属性点，丢金币刷金币，刷叠加物品等一些可能即将出现的。

**这类的，不要指望****G****盾来给你们包办了。我们也没那么多精力，我们恰逢其会知道怎么封，会封一波，毕竟我们不是专门封漏洞的****,****目前市场上有专门封漏洞的插件，各家登陆器出的插件都会封，比如绿盟，****XF,PJ,M9****，极限这几家都在做。****然后就是各位自己解决，比如丢金币漏洞，直接可以设置金币无法丢弃，刷属性点漏洞，不搞属性点就是。****叠加物品特修也是，设置叠加物品无法修理。**
