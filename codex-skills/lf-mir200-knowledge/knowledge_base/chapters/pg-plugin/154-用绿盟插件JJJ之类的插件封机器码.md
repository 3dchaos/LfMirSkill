# 用绿盟插件JJJ之类的插件封机器码

最近一些接到一些反馈说，一些玩家开挂禁止G盾加载，然后开启加速。
这种玩家，会在1分钟左右掉线，这种游戏玩法已经是毫无体验，纯属捣乱了，我们建议这些玩家可以直接封号，封机器码。
