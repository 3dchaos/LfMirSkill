# 开启十步一杀

为了解决部分服十步一杀出现延迟回头等问题PG增加了一个十步一杀功能（独立技能，和引擎的不共享cd）
PGRELEASESBYS

参数1=1开 0关
参数2=cd 单位： 毫秒

同时对十步一杀做了一写限制（PG和引擎自带均受控制）

![](../../assets/pg-plugin/PG插件3.48使用说明书/G盾盘古插件使用说明书/功能/开启十步一杀.files/开启十步一杀122.png)

键位设置最好和f10设置不要一样
