# 扩展常量

扩展常量

|  |  |
| --- | --- |
| **常量名称** | **含义** |
| <$PGPKPOWER> | 当前攻击造成的伤害，该变量只可用于QF脚本 |
| <$PGAUTOPICKSTART> | 该值为1时代表自动拾取开启 |
| <$PGAUTOPICKRANGE> | 自动拾取的范围 |
| <$PGATUOPICKINTERVAL> | 自动拾取的间隔 |
| <$PGDROPMONSTER> | 掉落物品的怪物名称，该变量只可用于QF脚本 |
| <$PGDROPMONSTERCLIENT> | 掉落物品的怪物名称去除数字，该变量只可用于QF脚本 |
| <$PGDROPITEM> | 掉落的物品名称，该变量只可用于QF脚本 |
| <$PGDAMAGEADD> | 通用攻击伤害加成百分比 |
| <$PGDAMAGEADD\_PLAYER> | 通用攻击伤害人物加成百分比 |
| <$PGDAMAGEADD\_MONSTER> | 通用攻击伤害怪物加成百分比 |
| <$PGMAGICDAMAGEADD> | 通用魔法伤害加成百分比 |
| <$PGMAGICDAMAGEADD\_PLAYER> | 通用魔法伤害人物加成百分比 |
| <$PGMAGICDAMAGEADD\_MONSTER> | 通用魔法伤害怪物加成百分比 |
| <$PGTARGETNAME> | 当前攻击对象名称 |
| <$PGTARGETHP> | 当前攻击对象血量 |
| <$PGTARGETMAXHP> | 当前攻击对象最大血量 |
| <$PGTARGETX> | 当前攻击对象X坐标 |
| <$PGTARGETY> | 当前攻击对象Y坐标 |
| <$PGSNDAITEMBOX1>...<$PGSNDAITEMBOX12> | 首饰盒1物品名称...首饰盒12物品名称 |
| <$PGG\_SNDAITEMBOX1>...<$PGG\_SNDAITEMBOX12> | 首饰盒1物品改名名称...首饰盒12物品改名名称 |
| <$PGSTARTAUTORECOVER> | 该值=1，则代表自动回收开启 |
| <$PGAUTORECOVERITEM> | 自动回收物品名称 |
| <$PGAUTORECOVERDELAY> | 自动回收延迟 |
| <$PGAUTORECOVEREXP> | 自动回收经验 |
| <$PGAUTORECOVERGAMEGOLD> | 自动回收元宝 |
| <$PGAUTORECOVERGAMEPOINT> | 自动回收泡点 |
| <$PGAUTORECOVERGOLD> | 自动回收金币 |
| <$PGAUTORECOVERCREDITPOINT> | 自动回收声望 |
| <$PGAUTORECOVERGAMEGIRD> | 自动回收灵符 |
| <$PGAUTORECOVERGAMEDIAMOND> | 自动回收金刚石 |
| <$PGAUTORECOVERGAMEGLORY> | 自动回收荣誉值 |
| <$PGMASKEDFIGHT> | 判断是否开启浑水摸鱼 1是0否 |
| <$PGKILLERRACE> | 死亡时击杀者类型 |
| <$PGKILLERNAME> | 死亡时击杀者名字 |
| <$PGKILLERNAMECLIENT> | 死亡时击杀者名字去除数字 |
| <$PGUSERSTATENAME> | 查看装备时对方的名字 |
| <$PGTARGETNAMECLIENT> | 当前攻击对象名称去除数字 |
| <$PGKILLMONNAMECLIENT> | 杀死怪物名称去除数字 |
| <$PGSLAVETARGETNAME> | 当前宝宝攻击对象名称 |
| <$PGSLAVETARGETNAMECLIENT> | 当前宝宝攻击对象名称去除数字 |
| <$PGSLAVETARGETHP> | 当前宝宝攻击对象血量 |
| <$PGSLAVETARGETMAXHP> | 当前宝宝攻击对象最大血量 |
| <$PGSLAVETARGETX> | 当前宝宝攻击对象X坐标 |
| <$PGSLAVETARGETY> | 当前宝宝攻击对象Y坐标 |
| <$PGDROPITEMNAME> | 杀死怪物正在爆出的物品名称 |
| <$PGSHOPSELLER> | 商铺卖家名称 |
| <$PGSHOPITEM> | 商品名称 |
| <$PGSHOPITEMIDX> | 商品序号 |
| <$PGSHOPITEMPRICE> | 商品价格 |
| <$PGSHOPITEMMONEYTYPE> | 商品货币类型 |
