# 爆率扩展

扩展了爆率格式

[示例]
原爆率格式
#CHILD
1/20 RANDOM //此爆率代表1/20的概率在下面物品中随机产出一件
(
1/1
1元价值物品
1/1
2元价值物品
1/1
5元价值物品
)

扩展格式
#CHILD
1/20 RANDOM [G3>4|1,U3>4,U4>U3|2]
//此爆率代表只有当G3>4且U3>4且U4>U3时才会进入1/20的随机
且物品爆出后G3减少1，U3减少2如果条件不满足则不会进入随机，用于精准控制物品产出，支持P变量、D变量、M变量、N变量、N扩展变量、I变量、G变量、U变量，支持逻辑方式大于(>)、小于(<)、等于(=)(
1/1
1元价值物品
1/1
2元价值物品
1/1
5元价值物品
)
