# 脚本放置地面物品

PG3.3.8新增放置地面物品
PG3.43新增参数8 自定义来源

PGThrowItemEx
//参数1:物品名
//参数2:范围
//参数3:是否立即拾取，0否1是
//参数4:保护时间，单位秒
//参数5:坐标X
//参数6:坐标Y
//参数7:房子地图名
//参数8:自定义来源 格式：来源地图|来源名称|来源角色|来源时间

注：由于触发者是玩家，请关闭引擎物品掉落提示，改用脚本提示（sendmsg等）

实例：

[@ONKILLMOB]
#if
#act
M.PGThrowItemEx 屠龙 0 1 60 <$KILLMONX> <$KILLMONY> <$map>
