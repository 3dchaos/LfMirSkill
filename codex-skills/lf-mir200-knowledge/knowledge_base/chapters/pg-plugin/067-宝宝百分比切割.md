# 宝宝百分比切割

PG3.3.9新增宝宝专用百分比切割

PGBDelMonHp

请在宝宝物理攻击触发[@PGSLAVEATTACK]和宝宝魔法攻击触发[@PGSLAVEMAGICATTACK]字段下使用,其他地方使用有可能会导致引擎出错

参数1：百分比或切割值

参数2：0:以当前HP的百分比 1:以参数1的值切割 2::以最大HP的百分比

参数3：”0不判断嘲讽 1判断嘲讽过的怪才切割

参数4：0都切割 1:本次切割只切割角色 2:本次切割只切割英雄 3:本次切割只切割怪物

参数5：分母基数(<=100等于100)

例子：

#ACT

；本次切割只切割怪物10点HP

PGBDELMONHP 10
1 0 3

#ACT

；本次切割只切割人物当前血量千分之8

PGBDELMONHP 8 0
0 1 1000
