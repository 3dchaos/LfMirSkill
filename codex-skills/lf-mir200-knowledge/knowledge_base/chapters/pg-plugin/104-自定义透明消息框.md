# 自定义透明消息框

PG3.47新增发送自定义透明消息框
PGSendMessage

参数1：计算模式
(0:以参数2、3作为直接绘制点
1:以自身角色XY作为计算基础点，再加上参数2、3
2:以游戏鼠标XY作为计算基础点，再加上参数2、3 )
参数2：X,支持负数
参数3：Y,支持负数
参数4：显示毫秒，0代表不限时，以毫秒为单位，1000等于1秒
参数5：是否可以ESC关闭，1可以，0不可以
参数6：颜色值，参考上线透明公告取值(GOM颜色0-255)
参数7：内容，支持变量，空格使用[#]代替
参数8：字体大小
参数9：是否开启背景 1开0关
参数10：背景色|背景透明度（透明度取值： 0-100）

例子:
#act
PGSendMessage 0 0 200 0 1 10 ESP自定义透明框
PGSendMessage 1 0 300 0 1 20 支持多种计算方式
PGSendMessage 2 0 400 0 1 30 支持各种颜色、定时显示、ESC键关闭
PGSendMessage 0 450 100 0 1 40 自定义透明框[#]\内容自定义填写、支持变量
PGSendMessage 1 450 180 0 1 50 自定义透明框[#]\内容自定义填写、支持变量
PGSendMessage 2 450 260 0 1 60 自定义透明框[#]\内容自定义填写、支持变量
PGSendMessage 0 450 340 0 1 70 自定义透明框[#]\内容自定义填写、支持变量
PGSendMessage 1 450 420 0 1 80 自定义透明框[#]\内容自定义填写、支持变量
PGSendMessage 2 450 500 0 1 90 自定义透明框[#]\内容自定义填写、支持变量
PGSendMessage 0 3000 200 0 1 100 自定义透明框
PGSendMessage 1 3000 300 0 1 110 支持多种计算方式
PGSendMessage 2 3000 400 0 1 120 支持各种颜色、定时显示、ESC键关闭
