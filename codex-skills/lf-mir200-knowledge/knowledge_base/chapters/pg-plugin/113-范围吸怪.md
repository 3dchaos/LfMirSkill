# 范围吸怪

PGMoveMonsters

参数1:坐标X
参数2:坐标Y
参数3:范围
参数4:目标类型(0=怪物，1=人物，2=怪物+人物)
参数5:最大吸取数量(0=不限制)
参数6:判断怪物等级(0=不判断)
参数7:判断是否嘲讽(0=不判断)
参数8:吸取怪物到范围(0表示吸到一个坐标)

注1：该功能小退恢复
注2：怪物等级不要超过
65535 级！
注3：参数8 大于0时为 吸到坐标范围附近的随机范围

注意：该功能小退恢复
实例

[@main]
#if
#act
PGMoveMonsters
<$X> <$Y> 5 0 0 0
SENDMSG 6
你已经将你范围5格之类的所有怪物都吸到身边来了！
