# 玩家说游戏掉线

更新中。。。
在日常反馈中，会经常遇到玩家说掉线的说法。 掉线有太多种类了，我大概说下：
掉线和G盾有没有关系，看玩家掉线的时候有没有G盾提示第三方，如果G盾提示第三方就是G盾T的玩家下线，如果没有，则是其他原因。
1.客户端插件安装失败

**如果是个别玩家提示安装失败提交反馈，说明一般是玩家电脑问题，解决办法一般是，让玩家重启路由器，****360****清理电脑垃圾****如果是全区玩家安装失败，请检查****G****盾控制台是否登录，****G****盾是否到期**

2.G盾提示玩家开挂，联系GM

**上线****1****秒就提示联系****GM****的，属于被封号的，可以在****G****盾控制台解封**

3.G盾提示第三方，请退出游戏

**这种的是主要得，玩家开挂游戏被检测到都提示这个，如果玩家反馈检测有误，请联系我们或者自行给玩家加白名单**

4.G盾提示第三方，请关闭网络加速器

**一般出现这个提示是因为在****G****盾上设置了检测网络加速器的按钮，检测到一些网络加速器了，一般这个开关默认是不开的，如果需要的话自行打开。**

5.G盾提示第三方，请重启电脑

**这种的，属于检测到一些带有很强外挂残留的外挂或者系统变速器，玩家重启电脑之后会恢复正常**

除此之外，还有没有提示掉线的，那就是其他问题了
1.网络不稳定

**WIFI****游戏的****4G****游戏的，一边游戏一边下载的，一些小运营商宽带的可能会出现**

2.家庭宽带换IP

**家庭宽带每过一段时间内就会切换下****IP****，切换****IP****必掉线，中国电信一般****1-3****天切换一次，其他宽带不了解**

3.服务器网络波动

**服务器受攻击，服务器卡了一下，服务器机柜网络波动，服务器丢包的都可能**

4.游戏界面闪退，消失

**玩家可能中劫持了，****360****急救箱急救或者重装系统**

5.游戏界面卡白屏，卡死

**一些玩家系统不稳定或者电脑配置问题，爱卡屏，使用简装功能有助于减少卡屏**
