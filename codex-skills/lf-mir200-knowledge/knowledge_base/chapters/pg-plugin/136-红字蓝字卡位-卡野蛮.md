# 红字蓝字卡位、卡野蛮

### **有部分用户反馈，开区遇到这样的红字，或者蓝色字提示**

![https://img.kancloud.cn/0b/7b/0b7bd6e4123187b95bbdc01a9a6174c6_339x130.png](../../assets/pg-plugin/PG插件3.48使用说明书/G盾游戏安全防护使用说明书/红字蓝字卡位、卡野蛮.files/image002.gif)
![https://img.kancloud.cn/20/d8/20d8b898a9f6bfcaf14b75ad9fd7eacf_348x89.png](../../assets/pg-plugin/PG插件3.48使用说明书/G盾游戏安全防护使用说明书/红字蓝字卡位、卡野蛮.files/image004.gif)
这种的问题，出在rungate上的选择-反挂设置里的间隔设置，和G盾无关，如果是部分人出现可能是那部分人开挂外挂或者误封，如果是很多人出现说明这里的设置并不准，可以关闭或者重新设置这里。
还有这种的
![https://img.kancloud.cn/b7/0a/b70af4aa576987261d8cdeda51333a7d_540x44.png](../../assets/pg-plugin/PG插件3.48使用说明书/G盾游戏安全防护使用说明书/红字蓝字卡位、卡野蛮.files/image006.gif)
这个问题一样的，出在rungate上的选择-反挂设置里的野蛮后攻击间隔设置。这里默认是1200，在这种设置下，正常野蛮是不会有问题的，但是当你野蛮别人，别人身后的空位不足，只退了1-2步，那么就会提示你这个提示，这是防御超级野蛮功能的设置。
解决办法是，把1200这个间隔设置的小一点，一般设置300-400是可以的。

上述2个问题，都不是G盾问题。
