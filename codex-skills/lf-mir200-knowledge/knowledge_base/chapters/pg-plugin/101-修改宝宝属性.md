# 修改宝宝属性

PG3.42新增修改宝宝属性
PGChangeSlaveAbility

//参数1:属性类型
0=HP,1=MaxHP,2=MP,3=MaxMP,4=AC1,5=AC2,6=MAC1,7=MAC2,8=DC1,9=DC2,10=MC1,11=MC2,12=SC1,13=SC2,14=移速,15=攻速,16=外观,17=准确,18=敏捷,19=等级,
//参数2:数值
//参数3:宝宝名
ALL或空代表所有宝宝
注：修改属性是直接修改基础属性，不是增加

例子：
[@main]
#IF
#ACT

PGChangeSlaveAbility
1 10000 ALL

PGChangeSlaveAbility 3
10000 ALL

sendmsg
6 您的所有宝宝最大HP和MP值修改为10000
