# 无限刀的速度消失

### **无限刀速度消失**

有人经常和我们反馈，无限刀的速度，在多久之后，或者在带上某个装备之后消失，这是很正常的，因为无限刀速度被版本内其他的脚本速度覆盖了。
打开QM，QF的文本，搜索下关键词CHANGESPEED，如果搜索到了，说明版本内原本是有脚本加速的，脚本加速在触发的时候会覆盖掉无限刀的速度，我们正确的做法是删除这些脚本速度。 或者你继续用脚本速度，就别用无限刀速度条了。 无限刀的速度也是可以使用脚本来实现，当初做了他，是因为他使用起来简单明了一点。
现在的B版，就没有无限刀的速度条，但是我们可以使用在QM文本里面加入CHANGESPEED 2
10来让出刀速度达到最快，和无限刀速度里面拉到10，毫无区别。
