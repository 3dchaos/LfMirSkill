# AB版本的区别

### **AB****两个版本的区别**

1.两个版本的检测外挂的云更新是同步的。
如果我们发现有外挂更新了，逃脱了G盾的检测，我们都是尽最快速度更新的。 如果我们让B版优先更新A版延后，那我们就是故意在放纵外挂施虐。这种事情在我们G盾是绝对不做的。即使这让B版的用户一直远低于A版用户也在所不惜，这是原则问题。

2.B版相对于A版功能上的优势
三技能的封锁，B版可以绝对完全的封死，A版还差了一点点，玩家可以手动准备技能，经过10秒的憋技能，是可以打出三技能的，这也是当初为了照顾一些手动操作比较犀利的老手玩家。
幻影功能的封死，B版是封死外挂幻影功能的，A版因为数据传输问题，导致一些数据在传输中丢失，无法做到完全的封死幻影并且不误封
魔法速度的限制：A版因为数据丢失问题，导致魔法技能的间隔判断无法做到，只能使用其他办法解决，比如rungate上限制，B版则直接自动对魔法速度进行智能限速。

3.B版相对于A版资源占用上的优势
当区里人数越多，M2上需要计算量就会越大，同时M2上G盾A版插件需要的计算也越多，这进一步加重的M2的负担，导致单区人多的服，A版会多吃了一些CPU。
所以我们一直建议单区人多的客户使用B版，随着反挂和外挂之间的对抗，以后的计算量可能还会增加，一些比较占用资源的反挂措施，也无法在A版上得到更新
