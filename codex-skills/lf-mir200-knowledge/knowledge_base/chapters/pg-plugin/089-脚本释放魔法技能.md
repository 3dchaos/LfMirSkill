# 脚本释放魔法技能

PG3.45增加脚本释放魔法技能
PGReleaseMagic (人物无需学习该技能)

参数1=释放技能id (支持自定义技能)
参数2=写释放技能id的技能效果 (0=默认 一般默认0即可 技能数据库Effect表示技能效果)
参数3=待定 （写0即可）
参数4=技能目标坐标方向 ( 1=自身坐标 ，2=攻击目标坐标 )

[@magicattack]
#if
equal <$CURRRUSEMAGICID> 11
#act
PGReleaseMagic 33 31 0 2
SENDMSG 6 你的雷电术触发特效攻击，对怪物释放了一次冰咆哮

注：战士蓄力技能烈火.逐日.开天使用PGActivateSkills 激活
