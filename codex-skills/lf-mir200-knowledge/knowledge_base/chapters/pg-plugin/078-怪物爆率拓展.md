# 怪物爆率拓展

怪物爆率拓展

PG3.3.9新增PGThrowItemEx2
//参数1:
物品名
//参数2:
数量

注：物品来源和击杀怪物一致

实例：

[@ONKILLMOB]
#if
#act
M.PGThrowItemEx2
屠龙


配合其他命令使用

;
可随机抽取物品，最后一个随机物品几率务必为1/1
#ACT
PGRandomText RANDOM\*{1/15}5钻石|{1/11}2钻石|{1/9}1钻石|{1/7}100元宝|{1/5}50元宝|{1/3}20元宝|{1/2}10元宝|{1/1}5元宝\*
| S3
M.PGThrowItemEx2 <$STR(S3)>
