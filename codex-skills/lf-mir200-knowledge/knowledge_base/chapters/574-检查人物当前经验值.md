# 检查人物当前经验值

**功能：**

检查玩家当前经验值。

**格式：**
CHECKEXP
控制符(=,>,<)  经验值(1 - 4000000000)< /FONT>

;==========================================
;检查人物的经验值是否等于指定值
[@checkexp2]
#IF

CHECKEXP =
5000
#SAY
您的经验值等于5000。
#ELSESAY
您的经验值不等于5000。
;==========================================

;==========================================
;检查人物的经验值是否大于指定值
[@checkexp2]
#IF

CHECKEXP >
5000
#SAY
您的经验值大于5000级。
#ELSESAY
您的经验值不大于5000。
;==========================================

;==========================================
;检查人物的经验值是否小于指定值
[@checkexp2]
#IF

CHECKEXP <
5000
#SAY
您的经验值小于5000级。
#ELSESAY
您的经验值不小于5000。
;==========================================
