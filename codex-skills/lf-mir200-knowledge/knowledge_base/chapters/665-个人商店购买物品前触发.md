# 个人商店购买物品前触发

**个人商店购买物品前触发**

**功能：**个人商店购买物品前触发
**格式：**购买前触发QF脚本
------------------------------------------------


**\*个人商店购买物品前触发 + 中止购买命令**

购买前触发 QF 字段 @BeginBuyUserItem


;QF触发脚本(简易示范脚本，具体自己发挥！！！！)
[@BeginBuyUserItem]
#IF
ISONMAP 3
INSAFEZONE
#ELSEACT
StopBuyUserItem
Messagebox 购买失败\\只能在盟重安全区使用购买功能



;QF触发脚本2(简易示范脚本，具体自己发挥！！！！)
[@BeginBuyUserItem]
#IF
CHECKGAMEGOLD > 999
#ACT
sendmsg 5 你购买<$CurUserName> 出售的个人商店物品<$CURITEMNAME> (<$G\_CURITEMNAME> ),ID:<$CurItemMakeIndex> ，花费<$CurItemPrices> <$CurItemMoneyType> (货币类型值：<$CurItemMoneyTypeValue> )，叠加数量<$CurItemOverlapCount>
#ELSEACT
Sendmsg 5 对不起，您的元宝不足。
