# 检查人物名称是否与IP匹配

**功能：**
    可以检查登录帐号与IP是否匹配。

**格式：**CHECKNAMEIPLIST NameIPList.txt

;==========================================
;检查人物的等级是否等于指定级别
[@checklevel0]
#IF
  CHECKNAMEIPLIST
NameIPList.txt
#SAY
您的登录帐号与指定IP匹配。
#ELSESAY
您的登录帐号与指定IP不匹配。
;==========================================

**列表文件格式:**此文件们于目录：Mir200\Envir\

NameIPList.txt

;==========================================
;人物名称 IP
GM001
192.168.1.123
GM002
192.168.1.124
;==========================================
