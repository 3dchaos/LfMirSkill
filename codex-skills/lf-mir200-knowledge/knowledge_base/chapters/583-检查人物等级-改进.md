# 检查人物等级（改进）

**功能：**

可以更为方便地检查玩家等级。

**格式：**CHECKLEVELEX 控制符(=,>,<)  等级数(1 -
65535)

;==========================================
;检查人物的等级是否等于指定级别
[@checklevel0]
#IF

CHECKLEVELEX =
50
#SAY
您的等级等于50级。
#ELSESAY
您的等级不等于50级。
;==========================================

;==========================================
;检查人物的等级是否大于指定级别
[@checklevel1]
#IF

CHECKLEVELEX >
50
#SAY
您的等级大于50级。
#ELSESAY
您的等级不大于50级。
;==========================================

;==========================================
;检查人物的等级是否小于指定级别
[@checkposelevel2]
#IF

CHECKLEVELEX <
50
#SAY
您的等级小于50级。
#ELSESAY
您的等级不小于50级。
;==========================================
