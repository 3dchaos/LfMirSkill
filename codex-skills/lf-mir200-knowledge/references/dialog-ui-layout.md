# Mir200 NPC 大对话框 UI 布局（Layout / Text / NewLine）

This note records the reusable syntax for building a big-dialog NPC menu using `OpenBigDialogBox` + `Layout` regions + `Text` buttons + `NewLine` line breaks. Source of truth: official chapters `186-打开NPC大对话框.md` and `038-Npc文字Text使用.md`, confirmed against real `老登四合一GitHub` scripts (e.g. `其它区域/火龙勇士-hlyszm.txt`, `其它区域/狐月岛阿狸-FOX02.txt`, `比奇城/火龙将军-0.txt`).

## 核心概念：布局区 Layout

大对话框不是用 `\` 换行写菜单，而是先在对话框上「开窗」定义若干个矩形布局区，再往每个布局区里放文字/按钮。

- `#L01` / `#L02` / `#L03` … `#L06` 是**布局区 ID**（数字编号，不是图片）。
- `#L1`（无前导 0）通常是**图片资源引用**，出现在 `<Img:~#L1:图片序号:资源编号:...>`，不要和布局区 ID 混淆。
- 工程里最常用的是 `#L02`。

### 定义布局区

```
<&Layout:~#L02:200:80:215:240>
```

- `&` 前缀 = **绝对坐标**（相对对话框左上角定位）；不带 `&` 则是相对上一个元素定位。
- `~#L02` = 定义一个名为 `L02` 的布局区。
- 后跟 `X:Y:宽:高`（可再追加一个 `边框色` 参数）。

### 嵌套布局（子窗口）

```
<&Layout:#L01~#L02:1:1:248:85:<$STR(N$边框色值2)>
```

- `#L01~#L02` = 在 `L01` 布局区**内部**再定义一个子布局 `L02`，坐标 `1:1:248:85` 是相对 `L01` 左上角的偏移。
- 用这种嵌套把一个大窗口切成左栏/右栏/底部等分栏。

## 往布局区里放内容

引用布局区时用 `#L02~`（布局 ID + 波浪号 `~`）作为元素的前缀，表示「放进 L02 这个区」。

### 多行文字 MText

```
<MText:#L02~:0:0:255:啊，真是不可思议……|
居然还有人能穿越这片被遗忘之地|
> 
```

- `MText` 用 `|` 作为换行分隔，多个 `|` 之间是同一段多行文字。
- 参数 `0:0:255:` 是 `X偏移:Y偏移:字号/色值` 一类显示参数（以具体脚本为准）。

### 按钮 Text

```
<Text:#L02~:就你一个人吗?:0:5{FCOLOR=251}/@就你一个人吗>
```

- `Text:#L02~:` 表示这是一个放进 `L02` 区的可点击按钮文字。
- `:就你一个人吗?` = 按钮显示文字。
- `:0:5` = `X偏移:Y偏移`（相对该布局区左上角的偏移量）。
- `{FCOLOR=251}` = 颜色属性（`FCOLOR` 是 0-255 色值，见 `mir200-256-colors.md`；还可加 `FSIZE`/`FNAME`/`FBOLD`）。
- `/@就你一个人吗` = 点击后跳转的标签。

### 换行 NewLine

```
<NewLine:#L02~>
```

- **`<NewLine:#L02~>` 等价于换行**——把后续元素定位到该布局区的下一行。
- 等价物：普通 `#SAY` 菜单里行尾的 `\`；大对话框里用 `NewLine` 显式换行，因为 `\` 在大对话框布局模式下的表现不同。

### 同一行内联多个按钮

多个 `<Text:...>` 紧挨着写（中间没有 `NewLine`）时，会**横向拼接在同一行**：

```
<Text:#L02~:护送:0:5{FCOLOR=255}><Text:#L02~:返回火龙迷宫:0:5{FCOLOR=251}/@返回火龙迷宫><Text:#L02~:500灵符:0:5{FCOLOR=255}>
```

注意：这里第一个 `护送` 和第三个 `500灵符` 都**没有 `/@标签`**，只有中间的 `返回火龙迷宫` 带跳转——说明 `Text` 也可以作为纯文字/占位显示，不一定非得是可点击按钮。

## 完整骨架（实战模板）

```
[@main]
#IF
#ACT
mov N$资源编号 0
OpenBigDialogBox <$STR(N$资源编号)> 16 1 4 0 0 1 384 23
#SAY
<Img:~#L1:27:<$STR(N$资源编号)>:0:-40>\
<Img:~#L1:34:<$STR(N$资源编号)>:144:-5>\
<&Layout:~#L02:200:80:215:240>
<MText:#L02~:0:0:255:第一行文字|
第二行文字>
<Text:#L02~:按钮A:0:5{FCOLOR=251}/@标签A>
<NewLine:#L02~>
<Text:#L02~:按钮B:0:5{FCOLOR=251}/@标签B>
<NewLine:#L02~>
<Text:#L02~:退出:0:20{FCOLOR=251}/@exit>
```

## 编辑注意事项

- **往已有大对话框菜单里加按钮**：找到菜单末尾最后一个 `<Text:...>/@exit`（或最后一个按钮），在其前面插入 `<NewLine:#L02~>` + 新的 `<Text:#L02~:按钮名:0:20{FCOLOR=251}/@标签>`。不要破坏原有的 `Layout` 定义和 `Img` 行。
- 布局区 ID（`#L02`）必须与 `Layout:~#L02` 定义的一致；`~` 后跟的 ID 写错会导致元素不显示或落到错误区域。
- 这些脚本是 GBK 无 BOM + CRLF，编辑时用二进制读 → decode('gbk') → 保持 `\r\n` → encode('gbk') 写回，禁止用文本模式读写（会把 CRLF 转成 LF，破坏文件）。
- 颜色用 0-255 色值（`FCOLOR=251` 之类），不要写 RGB 十六进制；查色值见 `references/mir200-256-colors.md`。
