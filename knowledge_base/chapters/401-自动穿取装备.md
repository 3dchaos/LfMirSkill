# 自动穿取装备

**功能：**
    自动穿取装备。

**格式：**    穿装备 TakeOnItem  装备名称 位置(0-12)
    脱装备 TakeOffItem 位置(0-12)

;==========================================
;穿装备
[@TakeOnItem]
#IF
#ACT

TakeOnItem 天魔神甲 0
#SAY
已经帮你穿上衣服了。
;==========================================

;==========================================
;脱装备
[@TakeOffItem]
#IF
#ACT

TakeOffItem 0
#SAY
已经帮你把衣服脱下来了。
;==========================================
