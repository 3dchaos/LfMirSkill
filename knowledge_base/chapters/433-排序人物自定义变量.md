# 排序人物自定义变量[!]

功能: 排序人物自定义变量.
格式: SortHumVarToListEx 变量名 变量路径 排序模式(0,1) 保存路径 保存模式(0,1) 变量文件是否绝对路径(0,1) 保存文件是否绝对路径(0,1)
说明: 排序模式
0=升序,1=降序


升序排序人物变量QQQQ:
[@main]
#IF
#ACT
SortHumVarToListEx
QQQQ ..\QuestDiary\测试.txt 0 ..\QuestDiary\测试A.txt
0


升序排序人物变量QQQQ,不保存人物变量:
[@main]
#IF
#ACT
SortHumVarToListEx
QQQQ ..\QuestDiary\测试.txt 0 ..\QuestDiary\测试A.txt 1
