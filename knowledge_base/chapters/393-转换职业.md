# 转换职业

**功能：**
    转换职业。

**格式：**    CHANGEJOB
职业名称(Warrior,Wizard,Taoist)

;==========================================
;转职业为武士
[@changejob0]
#IF
#ACT

CHANGEJOB
Warrior
#SAY
你的职业已经变成武士了。
;==========================================

;==========================================
;转职业为法师
[@changejob1]
#IF
#ACT

CHANGEJOB
Wizard
#SAY
你的职业已经变成法师了。
;==========================================

;==========================================
;转职业为道士
[@changejob2]
#IF
#ACT

CHANGEJOB
Taoist
#SAY
你的职业已经变成道士了。
;==========================================
