# 项目记忆 — LF知识库搭建

## 项目本质
本工程是 LF/Mir200 传奇引擎的帮助文档 CHM 转换的知识库 + Codex skill 项目。
但用户当前正在进行一个**衍生大项目**：基于本说明书做一款自研网页传奇文字游戏的**工程规划书**。

## 规划书项目关键决策（2026-09-05 已确认）
- **技术路线**：Python 编写游戏服务端，运行于 Ubuntu；客户端为 Web 浏览器（兼容移动端+PC端）；需要网游级安全性。
- **引擎定位**：规划书要充当"能支撑大型网游开发的骨架/地基"；引擎与第一款游戏合一（先做出传奇款，边做边抽可复用核心）。目标是引擎可交给他人，用规范丰富的功能API编写脚本，做出完全不同内容的游戏。
- **说明书定位**：当作功能清单目录对照——把传奇系统逐条勾选是否要做，避免遗漏系统。
- **玩法混合**：折中——实时社交(看到他人/组队/聊天) + 自动练级(个人打怪可离线/自动)。非纯放置，也非硬核全天实时抢怪。
- **伤害公式**：攻防二元（传奇式）：攻击下限~上限区间波动，扣减目标防御得实际伤害。
- **成长维度**：等级+基础属性、装备品质与词条、怪物与首领专属掉落、任务/转生目标线。
- **职业**：战法道三职业；**账号角色**：单角色。
- **社交深度**：基础社交(好友/组队/聊天) + 玩家交易/拍卖行。未选行会、师徒/结婚/排行榜(待后续可能补)。
- **PvP**：温和PvP + 行会战攻城（打怪打宝为主，野外可PK红名惩罚、行会战、沙巴克式攻城）。
- **商业化**：完全免费无内购（仅做游戏本体，规划书不含商业化设计）。
- **开发约束**：用户明确要求——不要编译/尝试用编译器，只做静态验证；编译运行由用户自己实现。
